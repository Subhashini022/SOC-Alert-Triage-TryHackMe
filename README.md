# SOC Alert Triage – TryHackMe

## Overview

This repository documents my hands-on practice with SOC alert monitoring and alert triage using the TryHackMe SOC Simulator.

The objective was to analyze security alerts, determine whether they were malicious or benign, classify alerts correctly, and understand the basic workflow followed by a SOC analyst.

## Investigation Approach

For each alert, I followed a basic SOC triage process:

1. Review the alert description.
2. Identify the alert type and severity.
3. Examine the available information and indicators.
4. Determine whether the activity is malicious or benign.
5. Classify the alert as a True Positive or False Positive.
6. Review the resolution and document the findings.
